# Dataset source and attribution

File: `mauna_loa_co2_weekly.csv`

This is the historical Mauna Loa weekly atmospheric CO2 dataset distributed through the Statsmodels datasets collection. It records weekly average atmospheric CO2 concentrations at Mauna Loa Observatory, Hawaii, over March 1958–December 2001.

The packaged CSV is kept locally for reproducibility and offline execution. It contains 2,284 weekly date rows, including 59 missing `co2_ppm` values. No rows were added to the source data.

Documentation:
- Statsmodels dataset documentation: https://www.statsmodels.org/stable/datasets/generated/co2.html
- NOAA Global Monitoring Laboratory CO2 trends data: https://www.gml.noaa.gov/ccgg/trends/data.html

Historical citation given in the Statsmodels dataset documentation:
Keeling, C.D. and T.P. Whorf. 2004. Atmospheric CO2 concentrations derived from flask air samples at sites in the SIO network. In *Trends: A Compendium of Data on Global Change*. Carbon Dioxide Information Analysis Center, Oak Ridge National Laboratory, U.S. Department of Energy.

This is a historical snapshot ending in December 2001, not a current CO2 monitoring dataset.
