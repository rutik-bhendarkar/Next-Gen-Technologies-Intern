# Week 1 Implementation and Work Log

## Objective

Complete the Python fundamentals practical assignment by building a Student Management System and documenting the implementation and testing.

## Monday - Python fundamentals

Topics applied: variables, strings, integers/floats, boolean values, input/output, type conversion and operators.

Implementation evidence: student ID, name, age, course and marks are stored as typed Python values; numeric values are converted and validated before use.

## Tuesday - Control flow and functions

Topics applied: `if/elif/else`, loops and reusable functions.

Implementation evidence: menu selection, grade calculation, repeated input validation and menu looping are implemented with conditions, loops and functions.

## Wednesday - Data structures

Topics applied: lists, tuples, sets, dictionaries and string manipulation.

Implementation evidence: student records are stored in a dictionary, marks are stored in a dictionary, subject names are maintained as an immutable tuple, student collections are converted to lists for display, and search normalizes text with `strip()` and `lower()`.

## Thursday - Exceptions, file handling and basic OOP

Topics applied: `try/except`, JSON file handling, classes, objects, properties and class methods.

Implementation evidence: `Student` and `StudentManager` classes separate student data from record management; JSON data is loaded/saved with protected file and data-validation operations.

## Friday - Integration, testing and documentation

The complete CRUD workflow was integrated: add, view, search, update, delete, performance summary, persistence and safe exit. Automated tests and manual end-to-end checks were performed, followed by README and screenshot preparation.
