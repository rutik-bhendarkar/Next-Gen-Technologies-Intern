# Week 1 Submission Guide

## What to submit

Use the folder contents in this package as your Week 1 submission. The internship task documents specify these core deliverables: Python source code, sample data, screenshots and README documentation.

## Recommended submission package

```text
Week_1_Student_Management/
|-- main.py
|-- data/students.json
|-- tests/test_student_management.py
|-- test_output.txt
|-- screenshots/
|-- README.md
|-- TESTING.md
|-- WEEK_1_WORK_LOG.md
|-- requirements.txt
`-- run.bat
```

## How to run before upload

From the project folder:

```bash
python main.py
```

For automated tests:

```bash
python -m unittest discover -s tests -v
```

## Submission portal

The supplied internship PDFs define the Week 1 deliverables but do not contain a reliable, specific submission URL. Therefore, use the submission page/link shown inside your internship dashboard or in the message/email from the internship provider. Do not invent a portal URL.

If the portal asks for a single file, upload the provided `Week_1_Student_Management.zip`. If it asks for a GitHub link, upload this complete folder to a repository and submit the repository URL.
